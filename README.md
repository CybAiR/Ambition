# Check for /src folder. For run rock detection files with ros2 launch you have to:
```
mkdir SKAMIELINY
cd SKAMIELINY
git clone (make sure there is only scr file with all files inside in SKAMIELINY folder)
cd src (check that all files are downloaded good)
cd ..
colcon build
source install/setup.bash
ros2 launch detekcja_kamienia detect_launch.py
```
